## 三、参考量级（判断实验是否合理的标尺）

> ⚠️ **以下为公开文献中同类工作的经验范围，不是本项目的实验结果，不得写入论文作为结论。**
> 用途：**合理性自查**。如果实测值大幅偏离该区间，优先怀疑实现有 bug，而非"效果特别好"。

| 对比方向 | 文献经验相对提升幅度 | 说明 |
|---|---|---|
| SASRec vs ItemCF（NDCG@10） | +30% ~ +80% | 序列建模相对协同过滤的提升最显著，差距通常很大 |
| SASRec vs GRU4Rec（NDCG@10） | +5% ~ +20% | 自注意力相对 RNN 的提升中等 |
| 多兴趣（MIND 类）vs 单兴趣（NDCG@10） | +3% ~ +8% | 多兴趣增益通常是个位数百分比 |
| 内容/属性融合（全量集，NDCG@10） | +1% ~ +5% | 交互充足时内容信息边际收益有限 |
| 内容融合（冷启动子集，HR@10） | +10% ~ +40% | 冷启动场景提升最明显，因为纯协同过滤几乎为 0 |

**合理性检查清单**：

- [ ] 本文模型 vs ItemCF 的 NDCG@10 提升是否显著（应远大于多兴趣模块的增益）
- [ ] 多兴趣模块单独增益是否在个位数百分比量级（若超过 15% 需警惕实现问题）
- [ ] E3 冷启动的相对提升是否**明显大于** E1 全量的提升（这是内容融合有效的关键证据）
- [ ] 所有指标是否都在合理值域内（HR@10 通常 0.3~0.8，NDCG@10 通常 0.15~0.5，视数据集而定）
- [ ] 三种子标准差是否足够小（若标准差与提升幅度同量级，说明结论不可靠）

## 六、错误案例分析

### 6.1 失败样本抽取方法


### 6.2 典型失败场景分类

#### 场景 1：兴趣漂移导致的失败

| 项 | 内容 |
|---|---|
| **表现** | 用户历史序列前半段是 A 题材，后半段突然转向 B 题材，模型仍推 A |
| **原因假设** | 注意力对近期行为权重不足；或位置嵌入对长程依赖建模能力有限 |
| **统计方式** | 失败样本中，用户最近 5 条记录题材与正样本题材一致但 Top20 无该题材的占比 |
| **案例** | 待填（`user_id` = 待填，序列 = 待填，正样本 = 待填，实际排名 = 待填） |
| **改进方向** | 引入兴趣漂移信号作为软约束；缩短序列窗口（30 → 20）；位置嵌入加近期权重 |

#### 场景 2：新番冷启动失败

| 项 | 内容 |
|---|---|
| **表现** | 正样本是交互数 < 10 的新番，未能进入 Top20 |
| **原因假设** | 内容向量表达不足（简介过短/缺失）；或内容权重的 0.5 仍不足以对抗行为路的强势 |
| **统计方式** | 冷启动子集中失败样本占该子集的比例 |
| **案例** | 待填 |
| **改进方向** | 提高冷启动内容权重；引入标签加权（细分标签参与编码）；新番单独排序池 |

#### 场景 3：多兴趣胶囊塌缩导致的失败

| 项 | 内容 |
|---|---|
| **表现** | 用户有多个题材偏好，但 Top20 几乎全是同一题材 |
| **原因假设** | 4 个胶囊学到相似的兴趣（塌缩），多样性与覆盖率不足 |
| **统计方式** | 检查失败样本对应模型的胶囊两两余弦相似度（见 `ablation-study.md` 5.5） |
| **案例** | 待填 |
| **改进方向** | 加入胶囊正交正则项；MMR 多样性重排的 λ 调小（更强调多样性） |

#### 场景 4：长尾物品曝光不足

| 项 | 内容 |
|---|---|
| **表现** | 正样本是低热度动漫，模型偏好推高热度作品 |
| **原因假设** | 训练样本中热门物品出现频次高，负采样未做热度校正 |
| **统计方式** | 按正样本的 `n_interactions` 分桶，统计各桶的 HR@10 |
| **案例** | 待填 |
| **改进方向** | 负采样改为按热度分布采样；加入流行度去偏（popularity debias） |

#### 场景 5：题材边界模糊导致的失败

| 项 | 内容 |
|---|---|
| **表现** | 正样本与用户历史题材"看起来不像"，但内容语义相近 |
| **原因假设** | 12 类题材归并过粗，跨题材的语义相近未被捕捉 |
| **统计方式** | 失败样本中，正样本与用户历史的内容余弦相似度 > 0.7 但题材无交集的占比 |
| **案例** | 待填 |
| **改进方向** | 题材分类细化（12 → 16）；内容向量在排序中的权重微调 |

### 7.3 局限性

> 必须如实撰写。可从以下角度展开：

| 局限 | 说明 |
|---|---|
| 数据集局限 | 仅使用 MAL 单一数据源，跨域迁移能力未验证 |
| 时序建模局限 | 序列长度限制 50，超长历史信息被截断 |
| 侧信息局限 | 仅使用文本内容特征，未引入图像、声优、制作公司等结构化特征 |
| 评估协议局限 | 采用留一法 + 100 负采样，与真实全库排序场景仍有差距 |
| 胶囊数固定 | K=4 为超参，未做自适应兴趣数建模 |
| 在线验证不足 | 演示系统用户量小，在线指标样本量有限，与离线结论可能不一致 |

### 7.4 未来工作

| 方向 | 具体设想 |
|---|---|
| 自适应兴趣数 | 用非参数方法让兴趣数随用户活跃度动态变化 |
| 多模态内容特征 | 引入封面图（CLIP）与音频（声优/OP）特征 |
| 负反馈建模 | 把"不感兴趣"反馈纳入训练损失 |
| 大模型增强 | 用 LLM 生成用户兴趣画像文本，作为额外的语义特征 |
| 在线学习 | 从每日离线全量改为流式增量训练 |
